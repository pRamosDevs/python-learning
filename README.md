# Python Learning

A structured journey to learn Python from fundamentals to advanced concepts through theory, exercises, challenges, projects, and practical software development.

## Goals

- Build strong Python fundamentals.
- Develop problem-solving and programming logic skills.
- Learn good programming practices.
- Learn Git and GitHub through practical use.
- Build progressively more complex projects.
- Create a reusable Python self-study resource.
- Progress from Python fundamentals to advanced concepts and practical software development.

---

## Learning Approach

Each chapter follows a structured learning process:

1. Study the chapter concepts.
2. Take concise handwritten notes for quick revision.
3. Create detailed chapter documentation in `README.md`.
4. Write and run practical code examples.
5. Complete the chapter exercises.
6. Review mistakes and important conceptual distinctions.
7. Commit the completed chapter using Git.

The objective is not simply to memorize Python syntax, but to understand how and why the language works and apply that knowledge through practice.

## Study Philosophy

The focus of this repository is:

```text
UNDERSTAND
    ↓
PRACTICE
    ↓
MAKE MISTAKES
    ↓
DEBUG
    ↓
REVIEW
    ↓
BUILD
```

The goal is to develop a strong understanding of Python rather than simply completing chapters.

Concepts should be understood well enough to:

- Explain them clearly.
- Recognize when they should be used.
- Distinguish them from similar concepts.
- Identify common mistakes.
- Debug incorrect code.
- Apply them to new problems.
